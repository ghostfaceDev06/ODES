# Ordinary Differential Equations (ODES)

---

## Repository Objective

This repository it was created with objective address Ordinary Differential Equations (ODES) or (EDOS, expression in Portuguese: Equações Diferenciais Ordinarias), your implementation at numeric methods to solve problems EDOS, utilizing these methods.

---

## Repository Content

Containing codes in Python and Matlab with comments goals and courses to reader.

---

## Academic Material

The material is extract at subject IC881 - MÉTODOS NUMÉRICOS PARA A SOLUÇÃO DE EQUAÇÃO DIFERENCIAIS ORDINÁRIAS - T01 (2026.2) offered for Math Department in Universidade Federal Rural do Rio de Janeiro (UFRRJ).

---

## Methods Address

- Euler
- Euler Modified
- Third Order Runge-Kutta
- Fourth Order Runge-Kutta
- Fehlberg Runge-Kutta
- Adams-Bashforth: 2 to 5 pass
- Adams-Moulton: 2 to 5 pass
- Predictor and Corrector Method
- Milne method
